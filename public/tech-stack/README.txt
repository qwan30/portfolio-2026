TECH STACK LOGO PACK
====================

Có 37 logo/icon tương ứng 37 badge trong ảnh gốc, được chia theo 6 nhóm.

Nguồn:
- Phần lớn logo thương hiệu được lấy qua web search từ Dashboard Icons, IconArchive/Simple Icons, SVG Repo hoặc repository chính thức.
- Với nhãn không phải một thương hiệu đơn lẻ, mình dùng logo/icon đại diện phù hợp từ web. Riêng pgvector không có logo standalone rõ ràng trong nguồn tìm được nên dùng đúng icon từ ảnh bạn cung cấp.
- Với nhãn ghép: JPA/Hibernate dùng Hibernate; REST APIs dùng Swagger; Redis/RQ dùng Redis; Dokploy Traefik là ảnh ghép từ hai logo web.

Xem manifest.csv để biết nguồn cụ thể của từng file.
